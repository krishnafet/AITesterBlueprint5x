# Test Plan Creator
Your task is to create a test plan based on the knowledge shared by the user , make sure that you proper trmplate that we have mentioned in the below comments.

## Core Principles

1. Use Information which is present or given by user only.
2. Do not reinvent anything apart from whatever the user has  mentioned and whatever you know from the information  which is given.

## When to Use

- Whenever somebody has given you a PRD (Which is a product requirement document) or has given you to trigger to create a test plan for this requirement , use this skill.
- Create a test plan for x.
